# 動畫小工坊 2.1.0 · 自由畫布

本機驗收版本，尚待使用者確認後才上傳 GitHub。

- 直接拖曳繪製矩形、橢圓及星形；鋼筆曲線、開放／封閉路徑與手繪。
- 形狀轉成可編輯節點，支援貝茲把手、平滑／尖角、精確插入及刪除。
- 形狀關鍵影格和可拖曳的空間移動路徑，含到達時間與切線旋轉。
- 畫布縮放／平移；靜態選取圖層 SVG 匯出。
- 14 種獨立屬性、10 種圖層；保留 184 場景套版、16 動作與 16 音效。
- Claude 包含實際幾何 API、schema、範例及操作說明。10 個 runtime，vector.js 在 layers.js 前。

未提供任意 SVG 匯入、布林運算、群組、遮罩或外部影音匯入。新資料需使用 2.1 runtime；舊版會丟棄新欄位。

驗證：Node 套件檢查、原生三比例渲染、180 格有聲 MP4 完整解碼與示範／節點／復原／視圖操作已通過。原位安裝保留作品與桌面捷徑；詳見 VERIFICATION.md。
