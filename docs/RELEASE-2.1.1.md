# 動畫小工坊 2.1.1 · 手動新增節點

提供可獨立下載的 Claude Skill ZIP 與完整來源 ZIP；不包含使用者作品或本機偏好設定。

- 新增「新增節點 N」工具與側欄入口。選路徑後單擊線段精準插入、點空白在所選節點後新增。
- 無形狀時逐點建立新路徑，至少兩點後 Enter 完成；Esc 取消草稿。
- 「插入線段中點」保留原有細分；曲線命中距離改用顯示像素，適用不同縮放、旋轉及比例。
- 全部形狀關鍵格同步新增節點，可復原。既有文字、圖片、動畫與專案格式保留。
