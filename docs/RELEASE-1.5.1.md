# Motion Workshop 1.5.1

新增「新增空白專案」，支援 macOS 檔案選單與 ⌘N。可設定橫式、直式、方形、秒數、畫質、FPS 與背景色；建立一幕無範本文字、圖層或音效的畫布，停在開頭並切到圖層編輯。

提供「先儲存目前作品，再新增」、直接建立與取消。取消儲存或儲存失敗時保留作品；建立後可復原／重做。自動儲存會換成新專案，介面會提示先另存原作。

公共 API 新增 MotionProject.blankProject(options)，Claude ZIP 同步更新引擎與說明。原有 184 個效果、144 個 Motion Prompt 套版、20 個可編輯配方及音效／轉場保留。
