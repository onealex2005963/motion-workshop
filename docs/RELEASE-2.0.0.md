# 動畫小工坊 2.0.0

多軌動畫編輯讓圖層、動作和屬性有各自的時間：從「圖層／動作」進入，使用「插入多軌動作示範」開始。

- 多軌拖曳、時段裁切、吸附、時間軸縮放與高度、關鍵格多選及複製貼上。
- 12 種獨立屬性關鍵格、自動記錄、自訂貝茲緩動。
- 16 種可疊加動作、參數調整、儲存動作組合、逐格轉換。
- 32 圖層、9 種圖層類型、非等比縮放、錨點、漸層、虛線、多選及對齊。
- 音效波形定位；原生 MP4 含內建音效。
- Claude 工具包更新 schema、runtime、指南及可編輯範例。

舊專案可用新版繼續編輯。新欄位仍屬 project v2，但舊 App 會忽略，請勿用舊版回存。

這一階段尚未加入鋼筆節點、任意 SVG、圖層群組、自訂遮罩或外部音訊／影片匯入。
