## 1.4.2 原生圖層拖曳排序

在隔離的 macOS WKWebView 實際測試：把底層色塊以拖曳把手移到最前方，畫布中的文字隨即被色塊遮住；以圖層名稱拖到兩層之間，清單與疊放順序一致。放到清單外取消，原順序不變；一次復原回到原順序。Option + ↑ 在取得焦點的圖層把手上成功上移並保留焦點。

透過原生儲存視窗輸出測試 JSON，確認 back-to-front 陣列順序、各層 4/2/2 個關鍵格及 3 個音效 cue 均保留。此測試版不讀寫使用者自動儲存，測試檔不納入公開套件。Esc、失焦與 pointercancel 走取消分支；未對所有輸入裝置做矩陣測試。

## 本機圖形與原生輸出驗證

原有 renderer 已在 Apple Silicon macOS 的 WebKit 執行驗證：40 種效果在固定時間重繪一致、不同時間有畫面變化；10 種轉場端點與合成中點可繪製；WebGL shader 可用。原生輸出曾實際產生 1400×720、30 FPS、234 影格、7.8 秒的 H.264 MP4，亦透過 CLI 工作佇列完成輸出。

這些原有 renderer 與公開套件的 runtime 相同，由 `npm test` 檢查。平台、字型及 GPU 驅動不同時不保證逐像素相同；尚未對每個瀏覽器／舊版 macOS 做完整矩陣測試。

新版網站範例與 DOM 介面另以瀏覽器實際檢查效果選取、播放／暫停、時間拖曳、標籤切換與點擊回饋。套件沒有測試或宣稱外部 Remotion / Premiere / ffmpeg 整合已自動運作。

1.3 編輯器另實際操作故事客製與套用，確認四幕合計 20 秒，並能復原為原本單幕作品、再重做。Claude 指令會帶入實際場景、配色與範圍；切換網站用途後提供對應 DOM 實作要求。40 種效果與 10 種轉場均已重新在原生 WebKit 逐項繪製檢查。

## 1.4 圖層與音效驗證（2026-10-20）

- Node：圖層正規化、重複關鍵格覆蓋、插值、七種緩動端點、命中測試、無效圖片 URL 拒絕、音效時間與轉場重疊、靜音、PCM WAV 標頭與取樣值。
- 16 個音效皆核對 PCM16 / 22050 Hz / mono；跨平台 render-audio.mjs 從獨立安裝位置輸出 10 秒 WAV（220500 samples），重複輸出拒絕覆寫。
- 原生 WebKit：重新檢查全部 40 效果、10 轉場及 WebGL；額外檢查文字／圖形圖層、內嵌 PNG 的實際畫素及關鍵格倒退定位重現。
- 原生影音：實際產生 2 秒、60 格 MP4，含一條 H.264 畫面及一條 AAC 單聲道音軌。另以獨立解碼器解碼，確認開始兩個 100ms 區間靜音，0.3s 與 1.3s 音效位置有訊號；影片影格時間為 0…59 / 30。
- 編輯器：實際新增示範、定位關鍵格、修改 X 值及復原；匯入 PNG、拖曳後儲存 JSON，確認內嵌圖片及新座標保留；試聽並放置音效；瀏覽器錯誤紀錄為空。

音效預覽必須由使用者啟動。圖層樣式不是所有欄位都可動畫；目前關鍵格控制 x/y/scale/rotation/opacity。沒有對所有舊 macOS、GPU 或所有瀏覽器做矩陣測試。

## 1.5.0 · 2026-10-21

Node 檢查確認 184 個效果、10 種轉場、8 套故事範本、184 張效果預覽、schema 與 runtime 一致；離線動效查詢、144 個共用 kit/元素程式語法、來源 SHA-256 與拒絕覆寫均通過。20 個圖層配方以三比例、兩 FPS、三長度與兩強度共 720 組設定驗證。

Apple Silicon WebKit 實際逐項繪製 144 個原版套版的三種比例，共 432 組；首末與逆向定位後的 RGBA 最大差異為 0。另檢查 cover、labels=false、loop=false 與縮放。實際生成三幕套版帶轉場 MP4：640×360、30 FPS、144 影格、4.8 秒與 3 個音效；原生渲染器亦完成全部 144 原始參考與 60 組圖層配方比例測試。

隔離原生 App 實際從字典搜尋 #105、插入套版、保留原場景、修改繁中標題、設定裁切填滿及一次播放，儲存 JSON 後核對 effect、reference 與 referenceTemplate 欄位。測試專案與截圖保留於本機工作區，不打包使用者作品。
