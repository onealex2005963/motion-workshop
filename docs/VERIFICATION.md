# 驗證範圍

## 可重跑的套件檢查

在根目錄執行 `npm test`，只需要 Node.js 20+，不需要網路或 npm install。

- 28 個效果 ID 與 catalog、Schema、實作一致，範例可正規化。
- 34 張 PNG 預覽的標頭、尺寸與目錄路徑有效。
- 6 種轉場在 30 / 60 FPS 的起迄、重疊與總長一致。
- 短片段轉場上限、未知效果拒絕、舊格式遷移與參數裁切。
- 可將整個 skill 複製到臨時專案，從複製後的位置獨立執行 CLI；已存在時拒絕覆寫。
- 網頁版與 skill runtime 逐位元一致；Markdown 本機連結存在；公開文字沒有電腦專屬 home 絕對路徑或常見金鑰格式。

`npm run pack` 產生 ZIP；可用系統解壓縮工具驗證完整性。完整來源包排除 .git、編譯產物、快取與個人專案。

## 本機圖形與原生輸出驗證

原有 renderer 已在 Apple Silicon macOS 的 WebKit 執行驗證：28 種效果在固定時間重繪一致、不同時間有畫面變化；6 種轉場端點與合成中點可繪製；WebGL shader 可用。原生輸出曾實際產生 1280×720、30 FPS、234 影格、7.8 秒的 H.264 MP4，亦透過 CLI 工作佇列完成輸出。

這些原有 renderer 與公開套件的 runtime 相同，由 `npm test` 檢查。平台、字型及 GPU 驅動不同時不保證逐像素相同；尚未對每個瀏覽器／舊版 macOS 做完整矩陣測試。

新版網站範例與 DOM 介面另以瀏覽器實際檢查效果選取、播放／暫停、時間拖曳、標籤切換與點擊回饋。套件沒有測試或宣稱外部 Remotion / Premiere / ffmpeg 整合已自動運作。
