# Motion Workshop 1.4.0 · 自由圖層與音效

原本只能調整整幕範本，現在可在同一場景疊加文字、圖形與自己的圖片，逐格決定它們如何移動，並把內建音效與畫面一起匯出。

- 每幕 12 個文字／圓角矩形／橢圓／線條／圖片圖層，拖曳、排序、顯示、鎖定及複製。可關閉底層範本，自由構圖。
- 調整位置、縮放、旋轉、不透明度、尺寸、顏色、描邊、圓角、字型、字重、對齊、混合模式及顯示起訖。
- 每層 60 個關鍵格、7 種緩動、5 種快速動作。支援任意時間定位、左右鍵逐格移動，Shift 每次移動 10 格。
- PNG／JPEG／WebP 匯入並內嵌專案，保留透明 PNG。圖片最長邊縮至 1200px，專案需小於 20 MB。
- 16 種 Kenney CC0 音效，試聽、場景時間放置、音量、播放速率、淡入淡出、總音量與播放預覽；原生 MP4 包含可選 AAC 音軌。
- 給 Claude 的 Skill、Schema、目錄、API 說明與完整範例同步更新。新的 render-audio.mjs 可在 Node.js 20+ 跨平台輸出混音 WAV，不需 App 或外部套件。

保留原有 40 效果、10 轉場、8 組故事。新欄位擴充 project v2，需使用 1.4 引擎／App；舊專案可直接開啟。尚不支援外部音樂、旁白或影片匯入、音訊分析及透明影片。

驗證：192 種故事設定、獨立 Skill 安裝與兩個 CLI、關鍵格／混音測試、40 效果與 10 轉場原生重繪、內嵌圖片畫素、實際 H.264／AAC MP4、介面匯入與拖曳儲存。來源及 CC0 授權附於 runtime/sounds/，詳見 THIRD_PARTY.md。
