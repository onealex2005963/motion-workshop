# Motion Workshop 1.5.0

新增 144 個可直接使用的 Motion Prompt 原版套版，加上原有 40 個效果，共 184 項。左側可直接套用；動效字典可搜尋、預覽及插入新場景。全部支援比例、速度、縮放、自訂標題、contain/cover、loop/once、額外圖層、10 種轉場與 MP4。原示範內部內容保留設計。

另有 20 組全圖層配方，支援文字、強度、錯開、關鍵格與 CC0 音效。字典可多選動效、逐項註記用途，儲存給 Claude 的交接指令。Skill ZIP 包含原始碼、144 張新預覽、完整繁中搜尋、離線 template/create/get/kit CLI 與使用指南。

來源為 Shohei Ohtaki 的 [Motion Prompt](https://github.com/showheyohtaki/motion-prompt)，MIT；保留作者、授權、固定快照與來源雜湊。Canvas UI 為互動示意，攝影風格為提示詞示範，不是照片濾鏡。無外部 API 或網路依賴。

驗證：184 項目錄與 schema、720 組配方設定、144 套版三種比例共 432 組原生繪製、逆向定位的 RGBA 完全一致，以及 4.8 秒／144 影格／3 個音效的原生 MP4。原生介面已實際操作套版插入、自訂標題、裁切填滿與一次播放並儲存 JSON。

下載 motion-workshop-skill.zip 給 Claude／Claude Code 使用；motion-workshop-source.zip 為完整原始碼。原生編輯器需 Apple Silicon macOS 與 Xcode Command Line Tools 自行編譯；Node 驗證與離線 CLI 可跨平台使用。
